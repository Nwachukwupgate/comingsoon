## How to use it?

Run this to install the dependencies:

```bash
npm install
# or
yarn
```

When that is done, run:

```bash
npm run dev
# or
yarn dev
```

Open your browser and go to http://localhost:3000

If you want the HTML version, run:

```bash
npm run build & npm run export
# or
yarn build & yarn export
```
